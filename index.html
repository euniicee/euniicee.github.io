Case study · In progress

Wrench, up close

The problem

Residence maintenance requests arrive as messy free text: several issues in one message, vague descriptions, typos, missing room numbers. Urgency also depends on context. A broken heater is an emergency in January, and "outlet not working" is a very different ticket from "outlet sparked". A keyword matcher can't tell those apart, and I know that from my own experience working in student housing.

The approach

I started with the domain, not the code. I wrote down how requests get routed, gave every ticket two labels (category and type) plus four urgency tiers, and set labelling rules so the test set stays consistent. All test data is synthetic and hand-labelled, with no real resident requests. The AI will split a message into tickets and return them in a strict format checked against my taxonomy, and it has to beat a plain keyword baseline. Accessibility needs are flagged only when a resident says so, never inferred, and only the flag is stored.

What's next

Next is the working triage pipeline and its evaluation against the labelled set. After that come follow-up questions for ambiguous messages ("the room smells" could be minor or a gas leak), duplicate detection with embeddings, a React dashboard, and deployment. The urgency tiers are a first draft that I'll refine against the labelled data.

M나NE, up close

The problem

I was tired of scrolling through generic top-10 lists that never matched what I actually wanted to watch. I wanted something personalized, built around my own taste, not a stranger's.

The approach

I built the whole pipeline myself: took a raw dataset of 2,000+ titles into a MySQL database, wrote the backend logic in Python, and built the React/TypeScript frontend on top. Added user authentication and a rating system so the recommendations actually improve the more you use it.

What's next

Right now it's local-only. Next up is getting it in front of other people to test, tightening the recommendation logic to weigh ratings more meaningfully, and wrapping it in a proper API layer.
